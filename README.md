# PDFdiff

JavaScriptでローカル実行できるオンライン差分チェッカー

PDFdiffは、2つのPDFファイルをブラウザ上で視覚的に比較するためのシンプルかつ強力なツールです。
変更前（旧）と変更後（新）のファイルを重ね合わせたり、スライダーを動かして違いを確認したりすることができます。

## 主な機能

- **視覚的比較**: 2つのPDFを重ね合わせ、差分を色分けして表示します。
  - <span style="color: #ff6666;">■</span> **赤色**: 削除・変更前
  - <span style="color: #6666ff;">■</span> **青色**: 追加・変更後
  - <span style="color: #cc66ff;">■</span> **紫色**: 共通部分
- **スライダーモード**: スライダーを左右に動かすことで、新旧のファイルを直感的に切り替えて比較できます。
- **マルチページ対応**: ページをめくって複数ページのPDFを比較可能です。
- **フルスクリーン表示**: 大きな画面で詳細を確認できます。
- **プライバシー**: すべての処理はブラウザ上で行われるため、ファイルがサーバーにアップロードされることはありません。

## 使い方

1. `index.html` をブラウザで開きます。
2. 画面上の「比較元（旧）」と「比較先（新）」に、比較したいPDFファイルをそれぞれアップロードします。
3. 「オプション」タブから比較モード（重ね合わせ または スライダー）を選択します。
4. 「前へ」「次へ」ボタン、またはキーボードの矢印キー（←/→）でページを移動して確認します。
